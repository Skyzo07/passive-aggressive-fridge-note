# Notes From a Passive-Aggressive Fridge

One funny passive-aggressive note that a smart fridge leaves for its owner — a single line, dry, petty and specific.

> I counted the yogurt cups. There were six. There are two. I am not a detective, but I am watching.

`main.ts` writes that line (98 characters, no trailing newline) to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```
